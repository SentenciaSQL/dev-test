# AppTrial Backend

Monolito modular Kotlin + Spring Boot 4 (Java 21).

## Módulos

Implementados en Fase 1: `identity`, `users`, `credits` (wallet + grant).  
Resto: marcadores de paquete para fases posteriores.

## Build

```bash
./gradlew bootJar
```

No hay suite de tests automatizados en este proyecto.

## Configuración

Ver `src/main/resources/application.yml` y `../.env.example`.
