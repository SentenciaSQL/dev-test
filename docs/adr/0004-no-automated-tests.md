# ADR 0004 — Sin tests automatizados

## Estado
Aceptado (restricción de proyecto)

## Contexto
El brief prohíbe tests unitarios, integración, E2E y carpetas de pruebas.

## Decisión
No se generan archivos ni dependencias de testing automatizado de producto. La verificación será manual / exploratoria.

## Consecuencias
(+) Cumple el requisito.  
(−) Mayor riesgo de regresiones; se mitiga con tipado, validación, ledger y revisiones.
